“高危”是怎么判断的？

“高危”表示本项目的人工核查优先级，不是洗钱概率或违法认定。只有已确认命中的规则组参与筛查；缺资料和口径不明的规则保留为无法评价。年龄、客户类型、卡数不会单独导致高危。

ABOUT THIS PROJECT

一个可以核对依据的规则模型作品

本项目把Excel中的五个业务规则评分模型实现为可交互的交易监测工具。核心是明确规则、正确计分和解释原因。

42组 / 68条

按真实合并单元格整理，保留F列阈值、C列分值和AND/OR。

54条已实现

14条子规则和7组关系待确认。数据不足时明确显示“无法评价”。

资金计算有边界

整数分计算，同币种配对；跨币种合计须有用户明确提供的当日汇率。

纯合成数据

固定种子20210506，包含正常、命中、边界及缺字段案例，未降低原始阈值。

怎样体验

  1. 直接看默认演示，或导入固定格式CSV。
  2. 选择期间和模型，点击“运行分析”。
  3. 点击账户，看大白话结论及原始模型得分。
  4. 展开规则，查看实际指标、阈值与证据；导出CSV。

这是业务规则评分与作品演示，不声称真实洗钱识别准确率。高危名单表示优先人工核查，结论不是违法认定。
